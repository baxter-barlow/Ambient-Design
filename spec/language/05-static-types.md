# 05 — Static types and domains

*Rhoform Language Specification · reserved · CC-BY-4.0 (see
[spec/README.md](../README.md))*

**This section is deliberately empty.** The static type system —
interface types (T1), the pin-role ERC lattice (T2), quantity typing and
dimensional algebra beyond literals (T3/T4), voltage domains with
component-mediated transfer semantics (T5), waivers (T6), and budgets
(T10) — lands here across M2, each rule in the same change that
implements its checker. **T5 transfer semantics land with R22
(AMB-54)**, exactly as the roadmap sequences it; recording that here is
what makes the omission a statement rather than a gap.

One part of T5 is already specified and is normative today: the
ground-architecture semantics (GA-1..GA-17), published as
*Rhoform Ground-Architecture Semantics* in the project's Notion Docs
collection (CC-BY-4.0). Its diagnostics catalog is transcribed into the
diagnostic registry — see [06 — Diagnostics](06-diagnostics.md) — and
this section will absorb or reference it, not restate it, when the T5
checker lands.
