# 04 — Elaboration

*Rhoform Language Specification · reserved · CC-BY-4.0 (see
[spec/README.md](../README.md))*

**This section is deliberately empty.** Elaboration semantics — total,
terminating, hermetic, effect-free evaluation; modules, instantiation,
arrays, parameters; stable source-derived identity (L1/L2/L3/L7) — land
here with the elaborator (AMB-44/R13), in the same change that
implements them. The rule from the spec README applies: a behavior
shipped without its section is a defect of that change.

Until then, the requirements document (§5.1) and the IR schemas
(`ir/netlist-ir.schema.json`, `ir/source-map.schema.json`) bound what
the elaborator may mean.
